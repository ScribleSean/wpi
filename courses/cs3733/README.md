# CS3733

Small software-engineering assignments, kept separate from the larger team application.

| Assignment | Contents |
| --- | --- |
| [A3](assignments/a3/) | React/TypeScript service-request interface |
| [A4](assignments/a4/) | Bumblor/Arabic number conversion, with a Vitest test file |

The [hospital team application](https://github.com/ScribleSean/Brigham-and-Womens-Hospital-Web-Application) remains standalone.
