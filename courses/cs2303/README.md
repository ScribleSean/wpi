# CS2303

C/C++ coursework from C23. Each `assignments/a1` through `assignments/a6` folder separates homework from lab work.

The source includes array operations, stack exercises, and ZIP-code CSV processing. Existing makefiles, Doxygen configuration, input files, and assignment readmes are retained. Generated HTML documentation, object files, and compiled executables were omitted.

Run commands from the individual homework or lab folder, following its readme and makefile. A compatible C/C++ toolchain is required. No course-wide build or correctness claim is made by this migration.

[Original repository and history](https://github.com/ScribleSean/CS2303).
