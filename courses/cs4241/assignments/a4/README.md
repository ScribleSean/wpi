# A4: React to-do application

Historical CS4241 exercise connecting a React frontend to Express and MongoDB through Vite Express.

Inspect `package.json`, install the declared dependencies, and set `MONGODB_URI`, `DB`, and `DB_TASKS` locally before running. Use only a disposable database. The old environment file is excluded and the connection URI now comes from `process.env.MONGODB_URI`.

The routes do not provide production-ready authentication or per-record authorization. This archive preserves a learning exercise, not a secure service. End-to-end database operation was not tested during migration.

[Original repository and history](https://github.com/ScribleSean/a4-sean-arackal).
