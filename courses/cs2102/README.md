# CS2102

Java coursework from B22, organized into `assignments/hw1` through `assignments/hw6`. Homework folders remain independent because they may reuse class names.

Use the source and test files in each homework folder to identify its dependencies. IDE state and compiled output have been omitted. There is no new shared Java build configuration, and the assignments have not been rerun during this migration.

[Original repository and history](https://github.com/ScribleSean/CS2102).
